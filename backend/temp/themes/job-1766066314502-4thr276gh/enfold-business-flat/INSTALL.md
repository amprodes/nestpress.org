# Installation Instructions

## Automatic Installation (Recommended)

1. Go to your NestPress admin dashboard
2. Navigate to **Appearance → Themes**
3. Click **Add New Theme**
4. Upload `enfold-business-flat.zip`
5. Click **Activate**

## Manual Installation

1. Extract `enfold-business-flat.zip`
2. Copy the `enfold-business-flat` folder to `/themes/`
3. Go to **Appearance → Themes** in admin
4. Find **enfold-business-flat** and click **Activate**

## Requirements

- NestPress CMS >= 1.0.0
- Node.js >= 18.0.0
- React >= 19.0.0
