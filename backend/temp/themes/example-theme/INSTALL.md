# Installation Guide: example-theme

## Quick Install

1. **Download** the theme .zip file
2. **Navigate** to NestPress Admin → Appearance → Themes
3. **Click** "Add New" → "Upload Theme"
4. **Upload** the .zip file and click "Install Now"
5. **Activate** the theme

## Manual Installation

1. Extract the .zip file
2. Copy the `example-theme` folder to `/themes/` directory
3. The theme will appear in Appearance → Themes
4. Click "Activate"
